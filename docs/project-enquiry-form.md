# Jouhara NK — Project enquiry

Description: Have an idea or a development challenge? Share a few details about your project so I can understand what you need and contact you about next steps. Please avoid including passwords or confidential documents.

| Question | Type | Required | Options |
| --- | --- | --- | --- |
| Your name | Short answer | Yes | |
| Email address | Short answer, email validation | Yes | |
| Company or website | Short answer | No | |
| What do you need? | Multiple choice | Yes | New website; Web application; Website redesign; Bug fixes or improvements; Other |
| Tell me about your project | Paragraph | Yes | Help text: What are your goals, who is it for, and which features do you need? |
| Estimated budget | Multiple choice | Yes | Under ₹25,000; ₹25,000–₹50,000; ₹50,000–₹1,00,000; ₹1,00,000+; Not sure yet |
| Preferred timeline | Multiple choice | Yes | Within 2 weeks; Within 1 month; 1–3 months; Flexible / not sure yet |
| Reference links | Paragraph | No | Help text: Share websites or examples you like, if you have any. |

Confirmation: Thanks for sharing your project. I’ll review the details and contact you by email.

Keep responses private, do not publish response summaries, and do not require respondent sign-in. Link responses to a new Google Sheet owned by Jouhara. Enable new-response email notifications if available.

Once created, put the public responder URL in `src/app/contact.config.ts` as PROJECT_ENQUIRY_FORM_URL. The portfolio will then show a Google Forms enquiry button automatically. Until then, the live CTA honestly opens a prefilled email draft; it does not save submissions.

## Additional client requirements

Added to the same published form:
- Mobile / WhatsApp number, including country code.
- Static, dynamic, mixed website or advice needed.
- New admin panel, integration with existing admin/CMS, no panel or advice needed.
- Device responsiveness requirements.
- Business social media profile links (optional).
- Content and media readiness.
- Available assets: branding, copy, photos, video/audio, product/service catalogues, existing files or data.
- View-only links to available project materials (optional).
- Integrations: forms/email, WhatsApp/calls, social feeds, payments, bookings, login, analytics, APIs/CRM and other needs.
